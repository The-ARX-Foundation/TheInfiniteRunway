## 🧠 **Phase 1: Preparation & Structure**

### ✅ 1. Define the Resume Structure (Sections)

| Order | Section Name                          | Notes                                                                                                  |
| ----- | ------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 1     | **Name & Contact Info**               | 14–16 pt name, city/state, no labels, professional email                                               |
| 2     | **Objective** *(optional)*            | Max 2 lines, e.g., “Seeking full-time role in medical software or [[Neurotech]], starting Fall 2025”       |
| 3     | **Education**                         | TAMU, full degree name, city/state, grad month/year (right-aligned), GPA 3.71, list minor/certificates |
| 4     | **Experience**                        | Work, research, relevant, or volunteer (reverse chrono)                                                |
| 5     | **Projects**                          | Capstone, personal, or class projects (include tech/tools)                                             |
| 6     | **Skills**                            | Break into “Proficient in” vs “Familiar with”; optionally include future certifications                |
| 7     | **Leadership / Involvement**          | Any clubs, teams, orgs                                                                                 |
| 8     | **Awards / Honors** *(if applicable)* | Omit high school unless exceptional (e.g., Eagle Scout)                                                |
| 9     | **Coursework** *(optional)*           | For early-stage [[Resumes]] or if highly relevant                                                          |

### 🧪 Experience

Use this format for each entry:

> **Company/Org Name**, Location
> *Your Title* — Date Range (right-aligned)
> • Action verb + what you did, why, how, and impact
> • Try to quantify (%, \$, time saved, etc.)
> • Avoid: "a, an, the"; get to the point

## ✏️ Phase 4: Bullet Writing Guidelines

For each bullet:

* [ ] Start with an **action verb** from TAMU list
* [ ] Follow **what → how → why → impact**
* [ ] Keep bullets **single-line** where possible
* [ ] **Quantify** with numbers (#, %, \$, X hrs saved)
* [ ] Add results: “resulting in...”, “providing...”, “achieving...”
* [ ] Avoid abstract adjectives (e.g., “good communicator”) — **show**, don’t tell
* [ ] Use the 3-part structure:

  > Developed \[X system] using \[Y method] to \[solve Z problem], reducing \[bad thing] by \[%].
