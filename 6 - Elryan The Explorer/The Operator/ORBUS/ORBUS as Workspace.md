# ORBUS as Workspace

## The Connection

"I need like 20 claude threads going at once. Need to split my window into a ton of em... need a 360 display screen with a chair that I can sit in. I miss my apple vision pro."

This is [[ORBUS]]. The spherical interactive display. The desire for it emerged organically from a real workflow need — multi-pane Claude orchestration across 15+ ARX workstreams. This is the strongest possible product validation: the inventor needs the invention RIGHT NOW for the work that's generating the invention.

## Self-Referential Loop

Building [[VELLUM]] (input glove) → need [[Thread Commander]] (multi-agent orchestration) → need [[ORBUS]] (360 display) → [[VELLUM]] is the input device for [[ORBUS]] → [[Thread Commander]] runs inside [[ORBUS]] → each tool validates the others.

The ARX hardware portfolio isn't a collection of separate products. It's a single integrated workspace that happens to be decomposable into independently useful modules.

## Apple Vision Pro Gap

The AVP was the closest commercial product to this vision. Its absence from the current setup is felt as a capability regression. ORBUS is the answer that doesn't depend on Apple's product roadmap.
