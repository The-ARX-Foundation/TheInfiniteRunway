# CLAUDE.md — ORBUS

## What This Is

**[[ORBUS]]** is a 360-degree spherical interactive display workspace concept under the ARX Foundation hardware portfolio. It emerged from a real workflow need: multi-pane Claude orchestration across 15+ ARX workstreams — the desire for an immersive surround display with a chair you sit inside.

## Project Status

**Phase:** Concept / early design. No codebase yet — currently documentation and concept validation.

## Key Concepts

- **Self-referential loop:** Building [[VELLUM]] (input) -> need [[Thread Commander]] (orchestration) -> need [[ORBUS]] (display) -> [[VELLUM]] is the input for [[ORBUS]] -> each tool validates the others
- **Apple Vision Pro gap:** AVP was closest commercial product; its absence is a capability regression
- **Decomposable workspace:** Not separate products — a single integrated workspace that happens to be modular

## Parent Context

- **Organization:** The ARX Foundation / [[Hopefully Abysmal]]
- **Persona:** [[The Operator]]
- **Related projects:** [[VELLUM]] (input device), [[Thread Commander]] (software layer)

## Things to Avoid

- Do NOT scope this as a VR project — it's a physical display, not a headset
- Do NOT decouple from the [[VELLUM]]/[[Thread Commander]] ecosystem without discussion
