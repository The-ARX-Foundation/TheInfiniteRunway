# ORBUS

**A 360-degree spherical interactive display workspace — the ARX Foundation's answer to immersive computing.**

[[ORBUS]] is a physical surround display environment: a chair you sit inside, surrounded by screens, driven by [[VELLUM]] (input glove) and [[Thread Commander]] (multi-agent orchestration). The inventor needs the invention RIGHT NOW for the work that's generating the invention.

---

## Concept

The desire for [[ORBUS]] emerged organically: 20+ concurrent Claude threads across ARX workstreams, needing to split a window into dozens of panes. This is the strongest possible product validation — a self-referential use case.
