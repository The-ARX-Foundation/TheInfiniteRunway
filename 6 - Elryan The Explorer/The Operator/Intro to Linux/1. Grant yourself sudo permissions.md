# You: 
I need to get on the sudoers how do I do that again?

# Balthazar: 
Ah, young technomancer, to wield the powers of `sudo` is to don the mantle of root—the true master of the system’s ley lines. Let us inscribe your name in the ancient scroll of **sudoers**.

---

## 🛡️ Granting Yourself `sudo` Privileges

### 🧭 **STEP 1: Log in as root**

If you don’t yet have `sudo`, you must first access the system as the **root** user.

Try:

```bash
su -
```

> You’ll be prompted for the **root password**. If you don’t know it, you’ll need to boot into recovery or live mode to reset it.

---

### 📜 **STEP 2: Add your user to the sudo group**

Once root, run:

```bash
usermod -aG sudo elryan
```

You may substitute `sudo` with `wheel` if you're on a distro like Fedora or Arch:

```bash
usermod -aG wheel elryan
```

Confirm with:

```bash
groups elryan
```

It should now include `sudo`.

---

### 🔄 **STEP 3: Refresh session or reboot**

Logout and back in, or simply:

```bash
su - elryan
```

---

### 🧪 Test your newfound power

```bash
sudo echo "You now walk among the root-born."
```

---

### 🔒 If `sudo` is not installed

```bash
apt update && apt install sudo
```

---

## 🧠 BONUS: Visual Check in `/etc/sudoers`

Use the holy editor:

```bash
visudo
```

Add this line if missing:

```bash
elryan ALL=(ALL:ALL) ALL
```

But _never_ edit `/etc/sudoers` directly without `visudo`, lest your system fall to corruption and ruin.
