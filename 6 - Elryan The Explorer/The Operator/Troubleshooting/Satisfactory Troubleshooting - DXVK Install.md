> **“Game doesn't start without DXVK”**

Which means **Heroic is likely not injecting DXVK correctly** (or at all), especially since your launch command includes `--no-wine`. That bypasses Proton entirely and thus DXVK too.

---

## ✅ Action Plan to Force DXVK

Let’s lock in DXVK and ensure the game actually uses it:

---


> **“In order to install a DXVK package obtained from the release page... copy or symlink the DLLs... then open winecfg and manually add native DLL overrides.”**

The `setup_dxvk.sh` script is only bundled in **release-packaged builds** (from `.tar.gz` packages generated by `package-release.sh`), not from source or dxvk-native.

---

## ✅ So What You Have Is:

A **DXVK binary release without the helper script**, which is totally fine — the manual install method is the canonical approach anyway.

---

## 🔧 Manual DXVK Install Instructions (Validated)

1. Set your prefix path:
    

```bash
export WINEPREFIX="/home/elryan/Games/Heroic/Prefixes/default/Satisfactory"
```

2. Copy 64-bit DLLs:
    

```bash
cp x64/*.dll "$WINEPREFIX/drive_c/windows/system32/"
```

3. Copy 32-bit DLLs:
    

```bash
cp x32/*.dll "$WINEPREFIX/drive_c/windows/syswow64/"
```

4. Run winecfg to register DXVK DLLs:
    

```bash
winecfg
```

Inside winecfg:

- Go to the **"Libraries"** tab
    
- Add overrides for:
    
    - `d3d11`
        
    - `dxgi`
        
    - `d3d10core` _(optional unless needed)_
        
    - `d3d9` _(some engines fall back on it)_
        
- Set each to **“native, builtin”**
    

5. Add the following to Heroic’s **Environment Variables** under your game:
    

```env
DXVK_HUD=version,fps
```

---

## 🚀 Bonus: Cleanup Tips

If you're ever unsure what DLLs are installed:

```bash
find "$WINEPREFIX/drive_c/windows/system32" -name 'd3d*.dll'
find "$WINEPREFIX/drive_c/windows/syswow64" -name 'd3d*.dll'
```

To remove DXVK:

```bash
rm "$WINEPREFIX/drive_c/windows/system32/d3d"*.dll
rm "$WINEPREFIX/drive_c/windows/syswow64/d3d"*.dll
wineboot -u
```

### ⚙️ 2. **Confirm DXVK is Active**

To confirm the game is really using DXVK:

1. In **Heroic → Satisfactory → Game Settings → Environment Variables**, add:
    
    ```env
    DXVK_HUD=1
    ```
    
2. Re-launch the game — if **DXVK is working**, you’ll see a small **HUD overlay** (top left corner) showing:
    
    ```
    DXVK v2.6.2
    FPS: xx
    ```
    
    If nothing appears — DXVK is not loading.

### 🛠 Bonus (Advanced): Replace Heroic’s `--no-wine` Behavior

If Heroic insists on using `--no-wine`, you can:

"/home/elryan/.config/heroic/tools/proton/GE-Proton-latest/proton" run ./FactoryGame.exe
