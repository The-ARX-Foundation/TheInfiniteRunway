# Thread Commander

**Multi-agent orchestration — 20+ concurrent AI threads in a tiling grid with inter-agent communication.**

Replace manual browser-tab switching with a purpose-built multi-pane AI workspace. Agents that talk to each other, shared context, domain-based thread routing, and spaced repetition across workstreams.

---

## Concept

The problem: 20+ concurrent Claude threads across ARX workstreams, managed by switching browser tabs. The solution: a tiling window manager for AI conversations with a message bus for cross-thread signals.
