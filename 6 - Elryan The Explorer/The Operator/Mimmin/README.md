# Mimmin

**A self-hosted, always-watching workstation intelligence. Zettelkasten that builds itself.**

[[Mimmin]] observes how you work and auto-refactors your thoughts into categorized, structured notes. Local-first, privacy-respecting, open-source. Once it's running, the system handles its own continuity — no more manual context transfer.

---

## Vision

- Ambient observation of workstation activity
- Auto-categorization into Zettelkasten structure (frontmatter, wikilinks, tags)
- Self-hosted on personal hardware — no cloud, no kill switch
- Replaces manual transfer documents with persistent system memory
