# ARX Homepage

**The ARX Foundation — [[The Archive Eternal]]. A library for one's soul.**

A windowed desktop-style homepage for the ARX Foundation. Sacred minimalism meets cathedral geometry. Black & white base that users paint through initiation.

---

## Quick Start

1. Drop `arx_homepage.jsx` into a React project (Vite, Next.js, etc.)
2. Import and render the component
3. All styles are self-contained (inline CSS-in-JS)

---

## Architecture

Single-component React application using a windowed desktop metaphor. Each content section (Mission, Pillars, Manifesto, Programs, Join) opens as a draggable, resizable window on a dark canvas.
