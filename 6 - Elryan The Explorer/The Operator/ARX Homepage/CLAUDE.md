# CLAUDE.md — ARX Homepage

## What This Is

A React single-page application for **The ARX Foundation** public-facing homepage. Built as a windowed desktop metaphor — sacred minimalism meets cathedral geometry. Pure black & white base that users "paint" through initiation.

## Tech Stack

- **Framework:** React (functional components, hooks)
- **Styling:** Inline CSS-in-JS
- **State:** `useState`, `useRef`, `useEffect`, `useCallback`
- **No build system yet** — single JSX file, designed for a React environment (e.g., Vite, Next.js)
