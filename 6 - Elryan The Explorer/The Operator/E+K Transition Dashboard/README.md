# E+K Transition Dashboard

**Life transition planning dashboard for Elryan + Kenya. Student loans, CACREP, housing search, asset liquidation.**

A React dashboard with workstream tabs, milestone tracking, and an integrated Zillow property pipeline for the housing search.

---

## Quick Start

1. Drop the JSX file into a React project
2. `dashboard-v2.jsx` is the latest version (includes property tracker)
3. Data persists to localStorage automatically

---

## Workstreams

| Stream | What |
|--------|------|
| Student Loans | Refinance planning, payment tracking |
| CACREP | Counseling program application/progress |
| Living Situation | Property search with Zillow status pipeline |
| Asset Liquidation | Sell/donate tracking for the move |
