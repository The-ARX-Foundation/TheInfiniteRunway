# HobbyTown St George

Standalone single-page website built for HobbyTown St. George, UT. Bold/action-packed aesthetic. Anchor-linked continuous scroll (no JS navigation).

## Sections

- **Home:** Hero, scrolling brand ticker, 3 feature boxes, about section
- **Products:** 4 categories (RC, Model Trains, Board Games, Crafts) with real brand names
- **Services:** Indoor track, repair services, event space
- **Events:** 5 sample events (need owner input for real calendar)
- **Contact:** Real address (215 W Saint George Blvd), phone (435-429-6936), hours

## Tech Stack

- Single HTML file, no external JS dependencies
- Google Fonts: Bebas Neue + Barlow
- CSS custom properties for theming
- Fully responsive with mobile breakpoints
