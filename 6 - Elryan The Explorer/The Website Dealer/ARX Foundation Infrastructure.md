# ARX Foundation Infrastructure

Nonprofit arm of [[Hopefully Abysmal Website|Hopefully Abysmal]]. Focused on open semantic web indexing, decentralized web infrastructure, and MCP-friendly [[Architecture]].

## ARX Browser

A decentralized-first, semantically-aware web client. UI inspiration drawn from Obsidian's design [[Philosophy]].

### Core Capabilities

- Native Handshake domain resolution (no browser extension required)
- Semantic web standards integration (RDFa, JSON-LD, Microdata)
- Local-first data storage with optional sync
- Model Context Protocol interfaces for AI agent integration
- Knowledge graph visualization of browsing/content relationships

## Domain Infrastructure

### Foundation Domains (Conventional)

- **arx.foundation** -- primary [[Trust]] anchor
- **arx.network** -- technical/developer facing
- **arx.directory** -- semantic index
- **openarx.org** -- open-source community

### Handshake Strategy

Pursuing .arx as a TLD on the Handshake blockchain. Would create a country-code-like domain space for housing client projects (e.g., tumadrestattoo.arx). Acquisition via Namebase auction system. Custom resolver infrastructure planned.

## CDN / Infrastructure Vision

- Custom CDN service under ARX Foundation umbrella
- Decentralized domain management for client sites
- MCP-friendly endpoints for AI agent consumption of web content
- Open semantic web indexing as core nonprofit mission
