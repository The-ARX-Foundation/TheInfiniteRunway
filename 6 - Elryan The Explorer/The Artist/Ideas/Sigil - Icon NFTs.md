Parameteic generation of grid based icons; connect the dot style.

Ideal output: sleep token logo type sigils

Parameters:

Number of 0s, axis/presence of symmetry, background / overlay shape

Make algorithm that fills array from list containing range(i) and 0's with trail of numbers from 1 through i, where i is number of spaces minus number of zeros.

EX 6×6 grid with axis of symmetry between columns 3 and 4; algorithmically solve for columns 1-3 and mirror. For each cell, place number until list is empty.

Resulting icons can then be minted; svg of path gives owner right to overlay path with any stroke / modifications to aesthetic so long that the geometric shape is intact.
